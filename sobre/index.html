O que faço

Qualidade do requisito à produção.

What I do

Quality from requirements to production.

Lo que hago

Calidad del requisito a producción.

  • Elaboração de testes a partir dos requisitos

    Casos e cenários de teste escritos a partir dos requisitos de negócio e conferidos com as regras de negócio.

    Test design from requirements

    Test cases and scenarios written from business requirements and reviewed against the business rules.

    Diseño de pruebas a partir de los requisitos

    Casos y escenarios de prueba escritos a partir de los requisitos de negocio y revisados frente a las reglas de negocio.

  • Testes de regressão e de liberação

    Versões semanais de manutenção e sprints de duas semanas: teste, regressão, liberação e reteste em produção.

    Regression and release testing

    Weekly maintenance releases and two-week sprints: test, regression, release and re-test in production.

    Pruebas de regresión y de liberación

    Versiones semanales de mantenimiento y sprints de dos semanas: prueba, regresión, liberación y nueva prueba en producción.

  • Testes de API

    Postman com scripts de teste em JavaScript para validar as respostas a fundo.

    API testing

    Postman with JavaScript test scripts to validate responses in depth.

    Pruebas de API

    Postman con scripts de prueba en JavaScript para validar las respuestas a fondo.

  • Dados e permissões

    Consultas SQL para checar os dados gravados, importação de notas fiscais conferida campo a campo (XML e PDF) e acesso por perfil de usuário.

    Data and permissions

    SQL checks on saved data, invoice imports checked field by field (XML and PDF), and role-based access.

    Datos y permisos

    Consultas SQL para verificar los datos guardados, importación de facturas revisada campo por campo (XML y PDF) y acceso por roles.

  • Automação de testes

    Playwright, Cypress, Maestro e Jest, da formação e dos meus próprios projetos, com CI no GitHub Actions.

    Test automation

    Playwright, Cypress, Maestro and Jest, from training and my own projects, with CI on GitHub Actions.

    Automatización de pruebas

    Playwright, Cypress, Maestro y Jest, de mi formación y de mis propios proyectos, con CI en GitHub Actions.

  • QA com apoio de IA

    Agentes de IA programam sob critérios de aceite que eu escrevo; eu reviso cada mudança, e uma revisão de QA independente confere cada versão.

    AI-assisted QA

    AI coding agents work under acceptance criteria I write; I review every change, and an independent QA review checks each release.

    QA asistido por IA

    Agentes de IA programan bajo criterios de aceptación que yo escribo; reviso cada cambio, y una revisión de QA independiente verifica cada versión.

Como trabalho

Toda mudança tem um teste e um revisor.

How I work

Every change has a test and a reviewer.

Cómo trabajo

Cada cambio tiene una prueba y un revisor.

  1. Plano e critérios de aceiteCada mudança começa pelo que ela precisa fazer e por como vamos saber que funciona.
    Plan and acceptance criteriaEach change starts with what it must do and how we will know it works.
    Plan y criterios de aceptaciónCada cambio empieza por lo que debe hacer y por cómo sabremos que funciona.
  2. Um agente de IA escreve o códigoUm item por vez, com os seus testes.
    An AI agent writes the codeOne item at a time, with its tests.
    Un agente de IA escribe el códigoUna tarea a la vez, con sus pruebas.
  3. Reviso cada mudançaAprovada ou reprovada, com o motivo. Nada conta como pronto sem esse sinal.
    I review every changePass or fail, with the reason. Nothing counts as done without that signal.
    Reviso cada cambioAprobado o rechazado, con el motivo. Nada cuenta como terminado sin esa señal.
  4. Barreiras automáticasTestes, lint e varredura de segredos a cada push, no GitHub Actions.
    Automated gatesTests, linting and secret scanning on every push, in GitHub Actions.
    Controles automáticosPruebas, lint y detección de secretos en cada push, en GitHub Actions.
  5. Revisão de QA independenteUm revisor à parte audita a versão inteira antes de ela sair.
    Independent QA reviewA separate reviewer audits the whole release before it ships.
    Revisión de QA independienteUn revisor aparte audita la versión completa antes de que salga.
  6. Varredura em aparelhos reaisUma varredura manual documentada no Android e no iPhone antes de publicar.
    Sweep on real devicesA documented manual sweep on Android and iPhone before publishing.
    Barrido en dispositivos realesUn barrido manual documentado en Android y iPhone antes de publicar.
